# English Tutor

Приложение для разговорной практики английского с говорящим анимированным преподавателем.

- Мозг: Groq (бесплатный тариф), модели GPT-OSS 120B / 20B, Qwen.
- Голос и распознавание речи: встроенные средства браузера (Chrome или Edge).
- Ключ Groq хранится только в браузере пользователя (localStorage) и в репозиторий не попадает.
- Урок, исправления и список слов сохраняются в браузере.

Файлы: `index.html`, `style.css`, `app.js`. Сборка не нужна — достаточно GitHub Pages.
